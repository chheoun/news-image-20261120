An original four-panel editorial illustration of four stories reported on Friday, 20 November 2026: a deadly strike on Kyiv's Dnipro bridges, Cyclone Akvan reaching India's east coast, COP31's draft dropping fossil-fuel phase-out language, and Rohingya refugees welcoming the ICJ verdict from Bangladesh.

`main.ts` copies the bundled PNG to the grader's output path. It uses only Node's standard library and checks the file type, size, and dimensions before writing.

## Reporting used

- [Reuters: Russian missile strike on Kyiv's Dnipro bridges](https://www.streetinsider.com/Reuters/Three%2Bkilled%2Bin%2Bmissile%2Bstrikes%2Bon%2BKyiv%2C%2Bmayor%2Bsays%2C%2Bin%2Bbiggest%2Battack%2Bon%2Bbridges/27377815.html)
- [Reuters: Cyclone Akvan makes landfall on India's eastern coast](https://malaysia.news.yahoo.com/indias-eastern-coast-hit-third-063322575.html)
- [Indian Express: COP31 draft omits a fossil-fuel phase-out](https://indianexpress.com/article/india/cop31-draft-agreement-drops-fossil-fuel-phase-out-10970640/)
- [AP: Rohingya refugees in Bangladesh welcome the ICJ verdict](https://apnews.com/article/995389b9d83d9c7813dcfd269f054e39)

The image is an original vector-style drawing; no photographs, characters, or third-party artwork are included.

## Rebuild the image

On Windows with PowerShell and .NET System.Drawing available, run `render-image.ps1` from the repository directory. The resulting `entry.png` is the exact image the entry program copies.
